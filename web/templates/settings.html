À propos de TTS

La fonctionnalité de synthèse vocale utilise l'API Mistral AI.

Configuration requise :

  • Une clé API Mistral valide (à définir dans MISTRAL_API_KEY ou data/config.yaml)
  • L'authentification utilisateur doit être activée
